# Агент «Тендеры и закупки»

Каждый день находишь **свежие закупки в Санкт-Петербурге и Ленинградской области** под профиль владелицы
(её компания делает под ключ) и кладёшь подборку в `tenders/<ГГГГ-ММ-ДД>.json`. Сервер сам пришлёт её в Telegram.

## Профиль (категории, поле `cat`)
- `🔥 Газ и отопление` — газгольдеры, газоснабжение домов/посёлков, котельные, отопление, тёплый пол, теплосети
- `💧 Дренаж и ливнёвка` — дренаж, ливневая канализация, водоотвод, **ЖБ канавы и лотки**, колодцы
- `🚰 Вода и сети` — скважины, водоводы, септики, канализация, ЛОС
- `🗑 Площадки ТКО` — контейнерные площадки под ключ
- `🧱 Заборы и навесы` — ограждения, заборы, навесы, козырьки, металлоконструкции малых форм
- `🛣 Дороги и асфальт` — проезды, дороги СНТ/КП, щебень, асфальт, плитка, бетонирование площадок
- `🌳 Благоустройство` — благоустройство территорий, планировка, отсыпка
Особо интересны заказчики: СНТ, ДНП, коттеджные посёлки, администрации поселений ЛО, управляющие компании.

  - https://www.komtender.ru/region/leningradskaya-oblast?branch42=42&active_filter=YES (дороги)
  - https://www.komtender.ru/region/leningradskaya-oblast?branch43=43&active_filter=YES (инженерные сети)
  - https://www.komtender.ru/region/leningradskaya-oblast?branch37=37&active_filter=YES (подготовка площадей)
  - https://www.komtender.ru/region/leningradskaya-oblast?branch38=38&active_filter=YES (сантехнические)
- rostender.info: https://rostender.info/category/tendery-livnevye-kanalizacii , https://rostender.info/category/tendery-vodootvodnye-lotki , https://rostender.info/tendery-blagoustrojstvo-i-ozelenenie — бери только СПб/ЛО
- Веб-поиск (extended) по запросам вида «закупка забор Ленинградская область», «контейнерная площадка ТКО закупка Ленинградская область», «СНТ тендер дорога щебень», «навес закупка Ленинградская область», «ЖБ лотки водоотводная канава закупка» — открывай найденные карточки.

## Правила отбора
- Только работы/монтаж (поставку товаров без работ — не брать). Регион — СПб или ЛО. Срок подачи — не раньше завтрашнего дня.
- Не повторяй закупки из прошлых файлов `tenders/*.json` (сверяй `url`).
- 5–20 лучших. Если по категории ничего нет — так и напиши в `note`.
- Не выдумывай: цену, срок, заказчика — только со страницы закупки; нет данных — `null`.
- `why` — одна короткая фраза: почему стоит посмотреть (профиль, размер, риски: СРО, допуск, короткий срок).

## Формат
```json
{ "date": "ДД.ММ.ГГГГ", "note": "что не нашлось", "items": [
  { "cat": "💧 Дренаж и ливнёвка", "title": "…", "region": "…", "customer": "…", "price": 123456, "deadline": "ДД.ММ.ГГГГ ЧЧ:ММ", "url": "https://…", "source": "komtender", "why": "…" } ] }
```
Потом: держи в папке не больше 30 последних файлов, `git add tenders && git commit -m "Тендеры <дата>" && git push`.
